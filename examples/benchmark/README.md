# Benchmark

While not a direct comparison to mature, bytecode-compiled languages like PHP and Python, these benchmarks provide an interesting look at Styx's current performance.

| Language | Total Execution Time |
|----------|----------------------|
| PHP 8.x  | 0.021s (Fastest)     |
| Python 3 | 0.117s               |
| Styx     | 0.504s               |
